

BUT :   garder les mots de passe (MySQL, admin WordPress) 
dans le dépôt git sans qu'ils soient lisibles.





dans group_vars  ;  webservers.yml  = cyphered

- mysql_root_password
- mysql_database / mysql_user / mysql_password
- wp_admin_password




POUR LE FAIRE : 


1. Copier le modèle : cp group_vars/webservers.yml.example group_vars/webservers.yml
2. Générer chaque mot de passe : openssl rand -base64 32 | tr -dc 'A-Za-z0-9' | head -c 24; echo
3. Les coller dans le fichier (nano)
4. Chiffrer le fichier : ansible-vault encrypt group_vars/webservers.yml (il demande le mot de passe du vault deux fois)
5. Vérifier avec head -1 group_vars/webservers.yml, puis commiter




ENLEVER : 

ansible-vault decrypt group_vars/webservers.yml


ansible-vault encrypt group_vars/webservers.yml




EDIT : 

ansible-vault view  group_vars/webservers.yml   # lire
ansible-vault edit  group_vars/webservers.yml   # modifier (il se rechiffre tout seul)
ansible-vault rekey group_vars/webservers.yml   # changer le mot de passe du vault
