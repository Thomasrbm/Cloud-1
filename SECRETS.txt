SECRETS : de zero jusqu'au fichier chiffre.


1. Generer un mot de passe aleatoire (a refaire pour chaque secret)
=> openssl rand -base64 32 | tr -dc 'A-Za-z0-9' | head -c 24; echo


2. Creer le fichier des secrets a partir du modele
=> cp group_vars/webservers.yml.example group_vars/webservers.yml


3. Y coller les mots de passe generes a l'etape 1
=> nano group_vars/webservers.yml


4. Choisir le mot de passe du vault (c'est lui que --ask-vault-pass demandera)
=> openssl rand -base64 32 | tr -dc 'A-Za-z0-9' | head -c 20; echo


5. Chiffrer le fichier sur place (il demande le mdp du vault, deux fois)
=> ansible-vault encrypt group_vars/webservers.yml


6. Verifier que c'est bien chiffre
=> head -1 group_vars/webservers.yml      # $ANSIBLE_VAULT;1.1;AES256


7. Relire ou modifier plus tard
=> ansible-vault view group_vars/webservers.yml
=> ansible-vault edit group_vars/webservers.yml


8. Deployer : Ansible dechiffre en RAM, le fichier reste chiffre sur le disque
=> ansible-playbook playbook.yml --ask-vault-pass


Mot de passe du vault perdu = fichier perdu (AES-256, cle derivee par PBKDF2).
